பாதுகாப்பு விதிகள்
1. Admin password-ஐ Operator-களுக்கு கொடுக்க வேண்டாம்.
2. Operator-களுக்கு operator.html link மற்றும் Operator password மட்டும் கொடுக்கவும்.
3. வேலை முடிந்ததும் சிவப்பு Logout button அழுத்தவும்.
4. 5 முறை தவறான password கொடுத்தால் 30 விநாடி login lock வரும்.
5. Password plain text project file-ல் இல்லை; access-config.js-ல் password hash மட்டும் உள்ளது.

PASSWORD மாற்றுவது
புதிய Admin / Operator password வேண்டுமெனில் access-config.js-ன் hash-ஐ மாற்ற வேண்டும்.
புதிய password-களை ChatGPT-க்கு தனியாக கொடுத்தால் புதுப்பிக்கப்பட்ட access-config.js உருவாக்கிக் கொள்ளலாம்.

முக்கிய குறிப்பு
இது GitHub Pages static website-க்கான password screen lock. மிக உயர்ந்த server-level security தேவைப்பட்டால் Firebase Authentication மற்றும் Firebase Database Rules தனியாக அமைக்க வேண்டும்.

WORK TIME / BREAK கணக்கு
Break fixed இல்லை. Operator கொடுக்கும் ஒவ்வொரு Out முதல் அடுத்த In வரை உள்ள உண்மையான இடைவெளி மட்டும் Actual Break.
First In முதல் Last Out வரை Total Presence; Total Presence - Actual Break = Net Active Working Hours.
8 மணி / 10 மணி என்று cap அல்லது தனி Overtime கணக்கு இல்லை. Net Active Working Hours அடிப்படையில்தான் Job Target மற்றும் Percentage வரும்.
